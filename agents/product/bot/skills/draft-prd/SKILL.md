# Draft a PRD

Follow the field contract in `references/prd-contract.md`.

## Procedure

1. Read the ticket summary, description, and any rejection notes from a prior `prd_review`.
2. Fill every required field. Prefer short paragraphs and bullet lists.
3. Acceptance criteria must be observable and testable (pass/fail).
4. Put unknowns in **open questions** instead of guessing.
5. Validate mentally against the contract before posting.

## Output shape (before Jira post)

```markdown
## PRD

### Problem
...

### Users
...

### Scope
...

### Out of scope
...

### Acceptance criteria
- ...

### Open questions
- ...
```
