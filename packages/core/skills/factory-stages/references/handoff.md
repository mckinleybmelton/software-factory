# Handoff template

End ticket-scoped specialist work with:

```text
Handoff: orchestrator
Ticket: <KEY>
Stage: <factory stage or n/a>
Status: <awaiting human review | blocked_* | …>
```

Optional lines when useful:

```text
Peer notes: <short context for the next specialist>
Artifact: <comment link or summary pointer>
```

Do not call other specialist peers from a specialist. The orchestrator routes.
